# Overview

Attemp to make simple todo console app.

## How to build

C++ version: 14

Run: `g++ todo.cpp`
Then open created file and write `help` to see command list.

## Commands

There are a few commands:

- add [text] - create new todo
- remove [id] - remove existing to by id
- check [id] - mark todo as solved by id
- uncheck [id] - mark todo as unsolved by id
